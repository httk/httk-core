httk.core.property_records
==========================

.. py:module:: httk.core.property_records

.. autoapi-nested-parse::

   Generated typed result records for the httk-core property definitions.

   Each class stores one value of its property definition in typed columns; see
   :mod:`httk.core.typed_records`. ``RECORD_KINDS`` maps each definition IRI to its class.

.. py:class:: AtomicForceRecord

   Bases: :py:obj:`httk.core.TypedRecord`


   Atomic force as a typed record.

   The force on one atom (the negative gradient of the energy with respect to the position of the atom), in electronvolt per angstrom, as a vector over ``dim_spatial`` in the Cartesian frame of the structure it belongs to.
   This property is the base of force statistics: a statistic of it (such as an error or a bias over a population of atoms) has the same shape, one value per Cartesian component.
   A null value means the quantity is not available or not recorded.

   :param atomic_force: The atomic force value. Unit: angstrom^-1*eV.
   :param product_of: The entries this value is a product of, as labeled edges.
   :param id: The human-readable entry id shared by all revisions; minted by the store when None.
   :param immutable_id: The per-revision immutable id; minted by the store when None.
   :param last_modified: The optional timezone-aware metadata timestamp.

.. py:class:: EnthalpyRecord

   Bases: :py:obj:`httk.core.TypedRecord`


   Enthalpy as a typed record.

   The enthalpy H = E_total + P V in electronvolt, with P the applied (external) pressure and V the cell volume. Extensive: refers to the whole simulated cell, not per atom.
   The reference/zero of the energy scale is method- and code-specific, so values are comparable only within one consistent computational setup.
   A null value means the quantity is not available or not recorded.

   :param enthalpy: The enthalpy value. Unit: eV.
   :param product_of: The entries this value is a product of, as labeled edges.
