httk.core.vectors.decimalvector¶

Exact decimal numbers as written in a CIF file: value, standard uncertainty and spelling.

A DecimalVector keeps what a number token says, not only what it is worth: 0.50 claims more digits than 0.5, 1.2345(6) carries the standard uncertainty 0.0006, and an unquoted 007 may be an identifier. The token text is the canonical form of the value, uncertainty and spelling, so equality and hashing compare tokens and distinguish 0.50 from 0.5; DecimalVector.numerically_equal() compares values. Entries may be the CIF gaps ? and . (DecimalGap).

Nothing here computes with the numbers: construction, equality, rendering and storage never expand a value, so 1e-999999999 is cheap. Convert to FracVector (FracVector(dv)) or floats for arithmetic; those conversions, and DecimalVector.precisions, apply the size bound of httk.core.exactmath.

class httk.core.vectors.decimalvector.DecimalVector(values)[source]¶

Exact decimal numbers as written, with optional standard uncertainties.

Any shape FracVector supports, including empty dimensions. Each leaf is a CIF numeric token, "?" or "." (nothing is stripped), a finite decimal.Decimal (canonical spelling, no uncertainty), an int (not bool), a DecimalGap or a DecimalScalar. Containers are lists, tuples or DecimalVectors and must be rectangular. A bare leaf needs DecimalScalar.

Parameters:

values (Any) – The nested entries.

Raises:

  • TypeError – For a float, Fraction, bool or other unsupported leaf, or a bare leaf.

  • ValueError – For a non-numeric string, a non-finite Decimal or ragged nesting.

The dimensions, () for a scalar.

property values: Nested[DecimalEntry][source]¶

The entries as nested tuples of decimal.Decimal and DecimalGap.

property uncertainties: collections.abc.Mapping[DecimalIndex, decimal.Decimal][source]¶

The stated standard uncertainties by index (read-only, sparse), in the value’s unit.

property spellings: collections.abc.Mapping[DecimalIndex, str][source]¶

The tokens that differ from the canonical rendering, by index (read-only, sparse).

property tokens: Nested[str][source]¶

The entries as CIF tokens (the spelling or else the canonical rendering, and ?/. for gaps).

property precisions: Nested[fractions.Fraction | None][source]¶

The precision each entry’s token implies (decimal_precision()).

The uncertainty is not part of the claim; gaps, integers and trailing points give None. A token whose exact value exceeds the size bound raises ValueError.
