httk.core.units¶

Parse and convert OPTIMADE Compound Unit Expressions with exact factors.

Symbols resolve against OPTIMADE unit, prefix and constant definition documents; default_registry() uses the upstream documents vendored with httk-core. Every relation-less unit is a base dimension named by its symbol (upstream kg is a base unit; there is no g). Relations are read only when a symbol is resolved, so a malformed upstream relation fails only for the symbols using it.
