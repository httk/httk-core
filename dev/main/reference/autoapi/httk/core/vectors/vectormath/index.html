httk.core.vectors.vectormath¶

Functional wrappers over the math module that also work on FracVector-like objects.

Each function first tries to dispatch to a method on the argument (so a FracVector computes an exact-rational element-wise result), and otherwise falls back to the corresponding math function on a plain scalar.

httk.core.vectors.vectormath.frexp(x, **args)[source]¶

Return the mantissa and exponent of x as the pair (m, e). m is a float and e is an integer such that x == m * 2**e exactly. If x is zero, returns (0.0, 0), otherwise 0.5 <= abs(m) < 1.

This decomposition is only meaningful for binary floating-point values; exact rational types such as FracVector do not support it — convert with to_floats()/to_float() first (a clear TypeError is raised otherwise).

(For vectors applied to each element and returns tuples nested in lists.)

Parameters:

  • x (Any) – The value to process element-wise.

  • **args (Any) – Additional options forwarded to the scalar or vector implementation.

Returns:

The mantissa and exponent, element-wise for vectors.

Raises:

TypeError – If exact rational input is not converted to a floating-point value first.

Return type:

Any

httk.core.vectors.vectormath.atan2(y, x, **args)[source]¶

Return atan(y / x), in radians, with the standard atan2(y, x) argument order used by math.atan2(), numpy, and httk.core.exactmath.atan2(). The result is between -pi and pi. The point of atan2() is that the signs of both inputs are known to it, so it can compute the correct quadrant for the angle.
